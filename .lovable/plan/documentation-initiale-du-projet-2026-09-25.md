# Documentation initiale du projet

## Objectif
Remplacer le README générique par une documentation en français, fidèle à l’état actuel du dépôt, et ajouter une courte spécification de projet.

## Livrables
- Un `README.md` présentant le projet, sa stack réelle, les prérequis, l’installation et les commandes disponibles.
- Un `PROJECT_SPEC.md` résumant le contexte, le périmètre actuel, les exigences techniques, les critères d’acceptation et les prochaines décisions produit.

## Principes
- Ne pas reprendre la configuration Replit importée, car l’application actuelle utilise TanStack Start et Bun/npm.
- Ne pas inventer de nom, de public cible ou de fonctionnalités métier encore non définies.
- Signaler clairement que l’écran principal est encore un modèle vierge.

## Vérification
- Relire les deux documents pour confirmer que les commandes correspondent au projet actuel.
- Vérifier que la mise à jour documentaire ne crée aucune erreur dans l’application.
